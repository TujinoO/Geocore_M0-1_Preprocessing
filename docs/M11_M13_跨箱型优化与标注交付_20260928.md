# M1_1 / M1_3 跨箱型优化与标注交付（2026-09-28）

本轮参考 `rock-agent-sci` 的“RGB 箱体结构证据 + 前景掩膜证据 + 人工复核”思路，但没有照搬 ZKH8 专用的 5/6/7 槽宽度、首隔板位置或自动通过条件。本项目须覆盖可变槽数和不同颜色/尺度的箱体。

## 已实现

1. M1_1 保留原三槽橙色严判分支；窄两槽箱通过橙色长向侧壁估计左右边界。普通梯度路径的输出新增 `geometry_review_required`，传递到 `needs_manual_review`。对 7520 像素大图，提高配对箱高并筛选跨宽度横梁峰，减少岩石内部纹理拆成半箱。
2. M1_3 保留经前景掩膜判槽的旧主路径；增加 2–8 槽 RGB 隔板格架候选，并在 `lane_detection.json` 中记录候选数、隔板位置、分数、次优数及分数差。它不自动覆盖掩膜。槽数冲突或 RGB 证据不稳写入 `review_manifest.json` 警告。
3. 新增 `layout.lane_dividers_x` 作为**人工确认后的**内部隔板坐标入口；空槽可以保留，并提示前景掩膜与物理槽位的差异。默认深度方向仍须野外记录核对。
   独立 M1_3 CLI 的入口是 `--lane-dividers-json`；综合 CLI 是 `--lane-dividers-by-box-json`，按 M1_1 的 `box_XXXX` 编号逐箱配置。这里需要的是校正后图像的像素坐标，不能直接把原始标注裁片 SHP 坐标当作它。
4. 在 `H:\Data_M1-1&M1-3_box_identification_and_reassembly\03_READY_FOR_LABELING` 交付 18 张候选 PNG、18 张 `.pgw`、36 套零要素 Polygon SHP、裁剪映射清单与标注说明。其他数字编号目录是诊断/筛选过程，不是待标注最终队列。

## 验证边界

- RGB ENVI 10/10 的头文件尺寸与实际字节数一致；未整体读入 20 GB 级原图。
- M1_1 对已知 ZKZ4-5 橙色批次仍检出 15 箱；对新增窄箱检出 10 个候选，首三箱左右范围由约 1415 像素收紧为约 680–690 像素。但检出数和裁幅变化不等于人工真值精度。
- 合成测试覆盖 2、5、6 槽物理隔板和空槽，M1_3 可接受逐箱人工隔板。真实多场景仍缺箱体/槽位标注，尚不能量化箱完整检出率、槽数正确率或重组顺序正确率，更不能宣称完全自动工程可用。
- `RGB-sbm...` 无箱负场景在 M1_1 普通路径仍可能产生候选，现一律标记待复核；这是下一轮应由负样本学习/规则门控解决的显性问题。

下一轮应先完成 SHP 标注及复核，按钻孔与采集批次隔离训练/验证/测试；评估每个物理箱的外框 IoU、完整箱召回、无箱误检、槽数正确率（按 2/3/5/6 分类）、分隔线误差及深度顺序。确认阈值后才允许自动通过，低置信、空槽或 RGB/掩膜冲突仍需拒绝或人工复核。
