# M0/M1 V5 固定版本说明（2026-09-28）

版本标签：`m0m1-v5-20260928`。本标签固定 M0→M1_1→M1_2→M1_3 的完整代码、配置、标注质检工具和审核接口；原始 ENVI 影像、人工 SHP、推理输出与大体积模型权重不进入普通 Git 历史。上一可回退标签为 `m0m1-v4-20260928`。

## 固定内容

- M1_1：橙色箱框与宽幅暗色箱候选识别、旋转校正、逐箱几何审核标记及人工校正接口。
- M1_2：继续使用 `core_mask_unet_v4`，模型版本 `v4.0.0-hard-example-20260927`；权重 SHA-256 为 `896495b3facae1369e95dc5e05def561b1cb7df08b15f2b214b7bcc0d747a32d`。权重从已有 V4 GitHub Release 安装，不在本次代码标签中重复上传。
- M1_3：可变槽数、人工逐箱隔板输入、来源级槽数冲突提示、RGB 暗隔板建议图、自动判槽失败时的审核预检、空槽保留、岩心柱重组、深度映射与图斑切分。
- 全流程：`--lane-dividers-by-box-json` 和 `--source-slot-priors-json` 接口保留；实际 SHP 槽面经同一次 M1_1 运行的旋转矩阵与裁剪偏移转换后才能输入逐箱隔板。

用户决定暂缓**真实深度和浅→深顺序的人工核对**。此决定不删除、不关闭深度映射或图斑切分功能；运行仍可接受深度参数并产生结果。未确认时必须保留 `depth_order_unverified` 和相应审核状态，不能将占位深度测试结果当作真实深度成果。

## 发布前回归和边界

- 本地 M0/M1_1/M1_2/M1_3/综合测试：45 项通过（Python 3.12、PyTorch 与 GDAL 可用的组合环境）；`git diff --check` 无差异错误。单用缺少 GDAL 的基础 Python 曾使 1 项 M1_2 测试因环境缺包失败，补入本机 GDAL 运行库后同一测试通过，并非算法失败。
- 18 张标注 PNG 及 SHP 重新审计：16 个正箱、2 个无箱负样本；`sample_005` 的 5 个 `SLOT_IDX` 已为 1–5。另有 `sample_011/012/013/017` 的面轻微越出图像边缘，原始标注未修改。

- `sample_004/005` 已在同一次真实 M1_1 运行中完成 SHP→校正图隔板坐标转换。`sample_005` 人工隔板把 V4 掩膜自动误判的 1 槽正确分为 5 槽；0–1 m 占位深度功能回归仅证明程序可运行，不证明真实深度。

因此本版本是**可追溯的人工审核辅助工程基线**，不是跨场景无人值守验收版本。新钻孔应用时必须审核箱数/箱界、槽数/隔板、掩膜与重组输出；真实深度与浅深顺序的核对按用户要求留到后续阶段。独立新钻孔真值与正式验收缺失应持续保留为已知限制。
