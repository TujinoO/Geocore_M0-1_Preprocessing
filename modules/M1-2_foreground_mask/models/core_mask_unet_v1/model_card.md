# CoreMask-UNet v1.0.0

This is the default model package placeholder for the Geo-Core AI M1-2 foreground mask module.

Put the released model weight file at:

```text
AGRS_semantic_segmentation-main/models/core_mask_unet_v1/weights.pth
```

The current manifest keeps the normalization values used by the existing prototype request example. Before formal release, update this model card with:

- training data source;
- annotation specification;
- train/validation/test split method;
- model architecture and training parameters;
- validation metrics;
- independent test metrics;
- typical success cases;
- known failure cases;
- version change log.
